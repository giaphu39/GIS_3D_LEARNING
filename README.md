# Hướng dẫn đọc

1. **[guide_arcGis_js.md](guide_arcGis_js.md) — Phần A, đọc trước:** học ArcGIS JavaScript và chuẩn bị demo bản đồ → POI → mô hình 3D → tour ảnh/hotspot. Chốt dữ liệu và tiêu chí UC04–UC08.
2. Sau phần A, **chọn một nhánh**:
   - **[guide_integrate.md](guide_integrate.md) — Phần B / phương án 1:** chuyển sang React, Node.js API và PostgreSQL; tự quản lý dữ liệu, ảnh/model; có hướng dẫn deploy tùy chọn.
   - **[guide_location_platform.md](guide_location_platform.md) — Phần C / phương án 2:** publish POI trên ArcGIS Location Platform, cấp quyền API và tích hợp web; ảnh/model/mạng tour vẫn do nhóm quản lý.

Không cần làm cả B và C. Cả hai vẫn có thể dùng nền/địa hình trực tuyến; chưa phải phương án offline hoàn toàn.

Các tài liệu là lộ trình triển khai, không có nghĩa ứng dụng đã có đủ mô hình và tour ảnh. Kiểm tra theo từng mốc khi thực hiện.
